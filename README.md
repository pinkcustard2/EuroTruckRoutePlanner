<h1>Euro Truck Route Planner</h1>

Euro Truck Route Planner was my A Level NEA project found the most efficient route from one city to another in the game Euro Truck Simulator. 

The program also allows multiple users and the ability to log deliveries each user has done, with stats like distance travelled and total weight transported.

<h2>Technical Aspects</h2>
<ul>
  <li>Used Dijkstra's algorithm to find the shortest distance between any two cities</li>
  <li>Stored users and user information in a 3NF database</li>
  <li>Used hashing algorithms so users' passwords wouldn't be able to be viewed</li>
  <li>Had different types of users which have different levels of access to the program</li>
</ul>
